	The mechanic I remade for this project was the soul meter from Hollow Knight. How this mechanic works is when the player hits an enemy with their standard attack it fills up the soul meter, which in turn can be expended to cast spells.

	I made sure to apply Time.deltaTime in the update method of the player script along with the movement logic to convert per frame changes into per second changes. In the attack script you can see examples of early vs late initialization: Where I wrote the max and starting ammo counts in the Awake method, and then used the start method to display the ammo count on screen when the game is loaded and every time it changes. In this project I also made use of Unity's input system, which let me map player actions to more abstract keybinds (The arrow keys to move, x to attack, and c to cast a spell).

	In order to replicate the mechanic I had to add on a couple more features to make it work as intended: Such as the simple ability to move around so the player can reach the enemy to hit them and to show that nothing happens if you miss your attack, as well as make a working attack feature (Which I briefly touched on in my initial pitch but decided to leave out of the big picture).
